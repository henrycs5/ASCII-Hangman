# ASCII Hangman
Date: 5/22/25\
The first project I did for my AP Computer Science A class using Scanner to read and store files. It's called ASCII Hangman because I created ASCII art to display each stage of hangman!

## Important Words?
- Reset Data: Clears saved stats.
- Yes: To continue.
- No: Ends the program.
- Skip: Skips word you couldn't figure out.
- guess who got powers? -> pretty sure: Instantly ends the current hangman game.
- Victim.txt is your saved data that is created
